# 💰 Personal Expense Tracker

## 📌 Project Overview

The **Personal Expense Tracker** is a React-based web application designed to help users manage their personal finances by tracking income and expenses. It provides a simple dashboard to monitor total balance, income, expenses, and transaction history.

## 🚀 Features

- **Dashboard:** View total balance, income, and expenses.
- **Add Transactions:** Record income and expenses with descriptions and categories.
- **Edit Transactions:** Update existing transaction details.
- **Delete Transactions:** Remove unwanted transactions.
- **Transaction History:** View all recorded transactions.
- **Filter Transactions:** Filter records by income and expenses.
- **Automatic Calculation:** Automatically calculate balance, income, and expenses.
- **Local Storage:** Save transaction data even after refreshing the page.
- **Responsive Design:** Supports desktop and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Vite
- Local Storage

## ⚙️ Installation and Setup

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**

```bash
cd personal-expense-tracker
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Run the application**

```bash
npm run dev
```

**Step 5: Open in browser**

```text
http://localhost:5173
```

## 💡 How It Works

1. Enter a transaction description.
2. Enter the amount.
3. Select Income or Expense.
4. Choose a transaction category.
5. Click the Add Transaction button.
6. View updated financial summaries.
7. Edit, delete, or filter transactions whenever required.
